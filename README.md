# EBV Knowledge System

Welcome to the EBV Knowledge System repository. This project builds a production-grade RAG and Knowledge Graph system for Epstein-Barr Virus research.

## Documentation Index

Please refer to the following critical project documents:

1. **[Engineering Specification](ebv-rag-engineering-spec.md)** - The core living architectural and infrastructure document.
2. **[Kanban Board](Kanban.md)** - Agile task tracking and sprint planning.
3. **[Agent Behavior](AgentBehavior.md)** - **CRITICAL**: The rules of engagement for all AI agents working on this codebase.
4. **[Gemini Docs](Gemini.md)** - Context and instructions specifically for Gemini and other LLM assistants.
5. **[Handover Document](Handover.md)** - A self-updating file used by agents to track current state and hand off tasks.

Please read the [Engineering Specification](ebv-rag-engineering-spec.md) to understand the system architecture, which emphasizes human-in-the-loop curation and rigorous confidence scoring.
